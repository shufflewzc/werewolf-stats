# 选手战绩分享卡（黑金版）

`player-performance-card-black-gold.png` 是已确认的固定版式视觉稿，用作动态战绩卡的设计基准。

- 固定区域：黑金背景、头像框、战队标记、排名、三项指标卡、右下二维码框。
- 动态内容：选手头像和姓名、战队、赛季排名、总积分、胜率、MVP、真实微信小程序码。
- 二维码由 `/api/miniprogram/share-code?player_id=<ID>` 调用微信小程序码接口生成；短场景值只携带选手 ID，扫码后由分享入口解析该选手最新赛事并打开对应详情页。
- 不显示“狼人杀赛事数据中心”或其他底部品牌文案；不使用狼、动物或月亮元素。
